# 首版边界与已知限制

- 默认 macOS 产品，当前自动化运行环境为 Linux。Linux 真窗口证据不能代替 macOS 安装、系统焦点策略、Gatekeeper、Apple Silicon/Intel 兼容测试。
- 当前构建未配置 Apple Developer ID 签名、公证、自动更新；不要当成已完成正式分发。
- 仅 VS Code 稳定版桌面窗口。准确激活依赖其内置 `workbench.action.focusWindow` 命令，运行时探测；旧版本会明确不支持。命令执行后没有焦点证据只显示已执行，操作系统可能拒绝前台聚焦。
- 扩展未加载的窗口无法统计。应用不会读取历史、标题或进程数补齐它们。扩展重载/崩溃时旧实例最多保留 35 秒；没有公开的持久窗口 ID，因此通过 TTL 收敛。
- SSH 只支持系统 OpenSSH、非交互认证和已信任主机密钥。远端需 Git 与 Python 3.8+；没有密码框、SSH 主机密钥授权向导或远端软件自动安装。
- 真实外部 SSH 主机、不同账号/namespace、Remote SSH 与 macOS 文件系统路径规则仍需目标环境验收。测试中的离线故障注入、远端扫描脚本本地执行不表示已在用户远端验证。
- Remote SSH URI 需显式映射 alias；其他 remote authority 类型显示未映射。远端目录通过符号链接打开但 URI 与扫描 realpath 不同且没有可用 Git API 时，宁可保持两个位置，不自动错误合并。
- 缺少明确 checkout 根报告时，只关联工作区的精确目录，不按父目录猜测仓库。远端 UI 扩展无法取得 Git API 时，子目录窗口不会自动计入其父 checkout；会话及其目录仍可直接查看和激活。
- 本机保守采用区分大小写，并对可访问路径 realpath；还未实现按挂载卷自动检测规则。SSH 环境可在创建时明确选择不区分大小写。跨平台 Windows 路径不在首版范围。
- 扫描上限是深度 8 / 15000 目录，隐藏子目录不遍历（可直接配置为根）。Git 查询单次超时 8 秒，远端整次 60 秒；部分失败时保留陈旧条目，并明确显示错误与最后成功时间。
- 工作集保留位置是用户组织信息；目录移动后不自动改写身份。可以重新添加新位置并编辑工作集。删除工作集不删除磁盘文件。
- 配置导入为替换而非多机同步。只保留最近一次导入前的自动备份；导出文件可能包含私有路径与 SSH 别名，应自行保管。
- 当前只验证 VS Code 适配，通用模型不意味着已经验证其他工具。没有云同步、终端/agent 会话、团队权限、插件市场或 Git 图形客户端。
